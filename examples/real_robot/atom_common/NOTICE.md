# ATOM hardware example

Copyright 2026 Dobot.

This example adapts the Dobot ATOM W and ATOM D 18-dimensional deployment implementations
provided for integration into Dobot Nexus. It is distributed under this
repository's Apache-2.0 license.

The ATOM and DH SDKs, RealSense drivers, robot firmware, model weights and
datasets are separate dependencies and are not redistributed by this example.
Retained SDK digests identify the expected integration versions; they do not
grant a license to those dependencies or certify another robot's operation.
