# WM / Wan2.2 接入设计

状态：**设计草案，尚未实现**。核对日期：2026-11-23。

本目录规划在现有 `core/` 中增加 `wm_base.py`、`wm_contracts.py` 等 WM 接口，
以 `models/wan22/` 作为首个模型接入；训练、推理和数据处理沿用现有职责目录。
本轮只创建 `wm` 分支和设计文档；文中的目录、类型、配置和命令均为拟议接口。

- [PLAN：架构、实现阶段与验收](PLAN.md)
- [PSEUDOCODE：数据、训练、生成和 Artifact 调用链](PSEUDOCODE.md)
- [SOURCES：现有仓库与官方代码依据](SOURCES.md)

首版建议先以 TI2V-5B 完成单模型链路，再接入 I2V-A14B 双专家；选择 A14B 优先时，
调整模型阶段的实施顺序即可，WM core 的职责不变。当前这是设计建议，尚未将具体型号作为用户已确认项。

两者都支持图像条件生成。机器人动作条件需要额外接入和训练，不能仅通过输入文本获得。
